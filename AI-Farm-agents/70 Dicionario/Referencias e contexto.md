# 🧭 Referências e contexto — "esse", "o segundo", "aquele"

← [[Dicionario de voz]]

> [!info] Uso
> Palavras que só fazem sentido com a conversa. O agente resolve com o que está **aberto** e em **foco** ([[Conversa continua]]); se a fala cita outro app/site, é pedido **novo**.

## Referências

| Fala | Aponta para | Como resolver |
|---|---|---|
| esse / essa / isso / isto / este / esta | o que está em FOCO na conversa | alvo em foco (última janela/aba usada) |
| aquele / aquela / aquilo / aquele lá | algo citado antes, não necessariamente em foco | procurar na conversa o item citado |
| esse aí / essa aí / esse daqui / esse aqui | o que está na tela agora | alvo em foco |
| ele / ela / nele / nela / dele / dela | o último app/site/arquivo citado | último alvo citado |
| lá / ali / aí | o lugar do último alvo | alvo em foco |
| o primeiro / o segundo / o terceiro / o último / o penúltimo | posição na lista visível | contar só itens reais (sem anúncios) |
| o de cima / o de baixo / o do meio / o debaixo | posição vertical na lista | ordem de leitura da tela |
| o da esquerda / o da direita / o do lado | posição horizontal | regiões da tela |
| o próximo / o seguinte / o anterior / o outro | item vizinho ao atual | relativo ao último aberto |
| o mesmo / de novo / igual | repetir com o mesmo alvo | último pedido |
| agora / então / e agora | continuar no que está aberto | alvo em foco |
| o vídeo / a música / o resultado / o produto / o link | item do tipo citado no alvo aberto | item visível daquele tipo |
| a planilha / o documento / o arquivo / o texto | documento aberto na conversa | janela do app em foco |
| o site / a página / a aba | aba do navegador da conversa | alvo web |
| o projeto / o código / o site que você fez | projeto de código da conversa | alvo code |
| a pasta / essa pasta / lá dentro | pasta aberta na conversa | alvo folder |
| o que você disse / o que você falou / aquilo que você achou | a última resposta do assistente | repetir/usar a última resposta |
| a primeira opção / a segunda opção / a que você sugeriu | opções oferecidas pelo assistente | fala do assistente no turno anterior |
| pode / manda / sim, faz / quero (após uma oferta) | aceitar o que o assistente ofereceu | executar a oferta no mesmo alvo |
| outro / outra / mais um / nova | NOVA instância (não o aberto) | pedido novo, sem alvo |
| tudo / todos / todas | todos os itens do alvo | confirmar se for apagar/enviar |
| nenhum / nada disso | recusa | não executar |
| bagulho / parada / negócio / treco / coisa | referência vaga | usar o foco; se não houver, perguntar UMA vez |
