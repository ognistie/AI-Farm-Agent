# 🔇 Muletas, hesitação e ruído

← [[Dicionario de voz]]

> [!info] Uso
> O que **não** é parte do pedido. Gaguejos contam uma vez; na autocorreção vale a **última** forma. Na conversa ao vivo, fala que não é dirigida ao assistente é **ruído**.

## Como tratar

| Fala | Como tratar |
|---|---|
| é... / éé / ééé / hã / hum / hmm / ahn / eh | ignorar (hesitação) |
| tipo / tipo assim | ignorar (muleta) |
| então / aí / daí / tá / né / ó / olha | ignorar no começo/fim da frase |
| deixa eu ver / pera / peraí / espera aí / calma | pausa do usuário: esperar o resto |
| como é que é / como é o nome / aquele... / esqueci o nome | usuário procurando a palavra: esperar ou usar o contexto |
| por favor / pfv / pfvr / faz um favor / faz favor / se puder | polidez (ignorar) |
| pra mim / pra gente / aí pra mim | polidez (ignorar) |
| rapidinho / só um pouquinho | ignorar (não muda o pedido) |
| mano / cara / véi / meu / bro | vocativo (ignorar) |
| assim / sabe / entendeu / tá ligado | ignorar |
| repetição: 'o meu, meu, meu' / 'abre, abre' / 'o o o' | gaguejo: manter uma vez só |
| auto-correção: 'abre o chrome, não, o edge' | vale a ÚLTIMA forma dita |
| frases cortadas no fim: 'abre o...' | pedido incompleto: perguntar UMA vez o que falta |
| barulho / tosse / risada / música de fundo | não é comando: ignorar |
| voz da TV ou de outra pessoa | se não for um pedido ao agente, ignorar |
| ok google / ei siri / alexa / hey google | nome de outro assistente: ignorar e entender o resto |
| testando / teste / alô alô / tá me ouvindo / um dois três | teste de microfone: responder curto que está ouvindo |
| risada / kkk / haha / rsrs | riso: ignorar |
| tosse / pigarro / espirro / respiração | ruído: ignorar |
| música ou tv ao fundo / legenda de vídeo / 'inscreva-se no canal' / 'obrigado por assistir' | frase fantasma típica do reconhecimento: descartar |
| 'legendas pela comunidade' / 'tradução e legendas' / 'amara.org' | alucinação clássica do Whisper em silêncio: descartar |
| frase em inglês solta no meio / 'thank you' / 'you' | provável alucinação: descartar se não fizer sentido no pedido |
| conversa com outra pessoa: 'pera, mãe' / 'já vou' / 'fala, amor' | não é para o assistente: ignorar na conversa ao vivo |
| pensando alto: 'onde é que tá...' / 'cadê...' / 'como é que faz' | esperar o pedido; se ficar só nisso, oferecer ajuda curta |
| frase repetida no fim (eco do áudio) | manter uma vez só |
| número dito duas vezes: 'dez, dez' | vale uma vez, a não ser que seja 'dez dez' de quantidade |
| final arrastado: 'abre o googleeee' | alongamento: ignorar |
| 'abre... é... o... excel' | pausas de hesitação: juntar o pedido |
