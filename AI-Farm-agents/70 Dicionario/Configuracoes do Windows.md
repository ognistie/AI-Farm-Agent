# ⚙️ Configurações do Windows — onde fica cada coisa

← [[Dicionario de voz]]

> [!info] Uso
> Jeito de falar → página exata das Configurações (`ms-settings:`). O [[Desktop Agent]] abre a página direto, sem procurar no menu; nomes de várias palavras daqui ("tela de bloqueio") valem mais que a palavra solta.
>
> [!warning] Só abrir
> Segurança, senha, recuperação e ativação: o agente **abre a página**, mas **não muda** nada sozinho.
